    06 — Case studies

    Three problems,
    and what changed.

    Built inside client and employer environments, so there are no public URLs. Open any one for the full story.

    Context

    Bugs and feature requests arrived from 59 live California locations across POS, kiosk, ordering, payroll and inventory. With no single view of the queue, work got picked up by whoever escalated hardest rather than by what mattered most.

    What I did

    Built a live Jira dashboard tracking every bug and feature request by priority, status, module, product and assignee, so developers could resolve strictly by priority — and so the backlog's real shape was visible to everyone at once.

    Result

    Open tickets fell from 350 to 168 between February and June 2026 — a 52% reduction, with resolution driven by priority rather than volume of complaint.

    Context

    During a production ERPNext rollout, approvals were the bottleneck in the supply-chain process — roughly five hours of manual handling per cycle, with deadlines and missing documents tracked by memory.

    What I did

    Built an approval workflow in n8n and Python, and configured and tested server scripts covering deadlines, reminders, submissions and missing-document checks. Delivered alongside data migration, formal UAT, system testing and user training for five supply-chain users.

    Result

    Cycle time improved by 40% — manual processing dropped from about five hours to one to three. Vendor coordination across five regional suppliers held at 95% on-time delivery.

    Context

    Nineteen restaurants, each with its own pay cycle, payday, approval deadline and time zone. Keeping them straight depended on remembering which state every location was in — which is exactly the kind of thing that fails on a busy week.

    What I did

    Built an internal payroll dashboard using Claude Code, centralising pay cycles, paydays, approval deadlines, run statuses and time-zone conversions into a single view with the state of every location visible at a glance.

    Result

    Dashboard reporting showed 95% of payroll runs completed on schedule, with the remaining delays traceable to missing documents or newly added employees rather than to tracking failures.
